# 0006 侧边栏项目分组与会话标题

- 日期：2026-09-27
- 状态：提议中。详细设计见 `docs/superpowers/specs/2026-09-27-sidebar-and-panel-design.md` §2

## 背景

- 侧边栏里的项目分组标题和会话行用同一种灰色，字号还更小，分组之间也没有边界，不同项目几乎分不出来。
- 会话标题取自 claude 设置的终端标题，全都是 `✳ Claude Code`，同一个项目下的几个会话也分不出来。

## 决策

- **分组样式：加强标题 + 分隔线。** 标题行为：文件夹图标 + 项目名 + 会话数 + ＋。项目名用 15pt bold **非等宽**字体、正文色，这是界面里唯一的非等宽字体。会话标题用 15pt、副标题用 12pt。第一版用的是 13pt 等宽，用户看过示例后觉得区分度不够，于是改成现在这样。分组之间用分隔线隔开，会话行缩进 18pt。
  - 另外考虑过"项目色标 + 竖线"和"项目卡片"两种方案，用户选择了最克制的这一种。
- **分组可以折叠**，点击标题行切换。现有的 ▾ 符号因此有了实际作用。折叠状态不跨重启保留。
- **会话标题的优先级**：自定义名称 → 第一条提问（跳过斜杠命令）→ `New session`。不再使用终端标题。
- **改名**：可以从右键菜单的 `Rename…` 进入，也可以双击标题。改名在原位进行；把名字清空就恢复默认标题。
- **标题写进恢复记录**（`OpenSessionRecord.title`，可选字段），恢复后的会话把它当作自定义名称。原因是 `--resume` 不会重放第一条提问。

## 后果

- 恢复之后，无法再区分哪个标题是第一条提问、哪个是用户改的名字，但显示效果相同。
- 旧格式的恢复记录没有 title 字段，这类会话恢复后显示 `New session`，直到用户发出下一条提问或改名。
- 不再订阅终端标题。如果以后 claude 能给出有意义的主题标题，可以把它作为第四个备选来源。
