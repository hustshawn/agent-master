# 0002 新建会话不必经过文件夹选择窗口

- 日期：2026-09-26
- 状态：已接受

## 背景

M1+M2 版本里，每次新建会话都会弹出 NSOpenPanel。在同一个项目里再开一个会话也要重新选目录；
`/tmp` 这类隐藏目录在对话框里看不到，只能按 ⌘⇧G 输入路径。

## 决策

- 侧边栏每个项目分组标题的右侧加一个 `＋`，点击后直接在这个目录开新会话。
- 底部的「＋ New session」改成菜单：
  - 列出最近用过的目录，最多 10 个，最新的在最前，悬停显示完整路径。
  - 分隔线，然后是「Choose Folder…」，点它才打开 NSOpenPanel。
- ⌘N 在当前选中会话的目录开新会话；没有选中会话时打开 NSOpenPanel。⌘⇧N 为「New Session in Folder…」，总是打开 NSOpenPanel。
- 最近目录（`RecentProjects`）存在 UserDefaults 里，重启后仍保留：
  - 每次成功开会话时，把该目录移到列表最前，并去掉重复项。
  - 读取时过滤掉已经不存在的目录。

## 后果

- 记录的路径是 NSOpenPanel 返回的真实路径，比如 `/private/tmp/am-demo`，分组名不受影响。
- ⌘N 的行为由"总是打开选择窗口"改成了"在当前项目开"。这一点是设计阶段补充的，用户确认后采纳。
- 以后接入多个 agent 时，这些入口要加上 agent 选择（见 0004）。
